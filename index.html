ANTES DE ABRIR

Como o VAULT funciona?

O VAULT é uma ferramenta de criptografia que transforma um texto comum em conteúdo protegido por senha.

01
O que é?

O VAULT é um cofre digital que protege textos, senhas, mensagens e outras informações utilizando criptografia.

02
Por que usar?

Em vez de deixar uma informação sensível em texto aberto, o VAULT transforma esse conteúdo em dados que não podem ser lidos sem a senha correta.

03
É enviado para algum servidor?

Não. A criptografia é executada pelo próprio navegador utilizando a Web Crypto API.

04
O que protege o conteúdo?

Uma senha mestra é transformada em uma chave criptográfica. Essa chave é utilizada para proteger o conteúdo.

01
Você digita o conteúdo

Pode ser uma mensagem, senha, anotação ou qualquer outro texto que você queira proteger.

02
Você cria uma senha mestra

A senha não é utilizada diretamente. O sistema usa PBKDF2 para transformar essa senha em uma chave.

03
Uma chave criptográfica é derivada

Um salt aleatório é combinado com a senha durante a derivação da chave.

04
O conteúdo é criptografado

O AES-256-GCM transforma o texto original em ciphertext, adicionando autenticação para detectar alterações.

05
O VAULT gera o pacote

O resultado recebe os parâmetros necessários para que posteriormente possa ser descriptografado.

1
Abra o VAULT

Entre no cofre digital e escolha se deseja criptografar ou descriptografar um conteúdo.

2
Digite o conteúdo

Escreva ou cole a informação que deseja proteger.

3
Defina uma senha mestra

Quanto mais longa e imprevisível, melhor. O gerador integrado também pode criar uma senha aleatória.

4
Execute a operação

Clique em criptografar. O navegador executa todo o processamento localmente.

5
Salve ou copie o resultado

O pacote criptografado pode ser copiado ou salvo em um arquivo .vault.

6
Para recuperar

Cole o pacote no VAULT, escolha descriptografar e informe a mesma senha utilizada anteriormente.

AES AES-256-GCM

Algoritmo utilizado para criptografar o conteúdo. O modo GCM também permite verificar a autenticidade dos dados.

KDF PBKDF2

Processo responsável por transformar a senha mestra em uma chave criptográfica.

256 SHA-256

Função utilizada pelo PBKDF2 durante o processo de derivação da chave.

RNG Crypto.getRandomValues

Fonte de aleatoriedade criptográfica usada para gerar salts, IVs e senhas aleatórias.

WEB Web Crypto API

API nativa do navegador utilizada para realizar as operações criptográficas.

LOCAL Processamento local

O processamento acontece no dispositivo do usuário, sem depender de um servidor para executar a criptografia.
